# DEMETER ATELIER / 德墨忒尔矫形外科研究所

以虚构私立外科研究所为主题的滚动怪诞恐怖网站。页面从一家克制、可信的矫形外科机构开始；向下滚动后，"矫正"逐渐暴露出它真正含义：把身体改造成图纸上的样子，而且没有"术后"。

**本项目为原创虚构互动体验，不代表任何真实机构或医生，不提供医疗、手术、诊断、建议或预约，也不收集个人或健康信息。** 所有病例、医生与记录均为虚构。

## 页面与交互

六个滚动阶段（`body[data-stage="0"]` 至 `"5"`）：

1. **首屏** — 冷瓷白的手术室实景、克制的机构气质："我们不改善身体，我们只纠正它。"
2. **矫正项目** — 面部对称、多余部分移除、夜间观察；第三张卡片文案开始出错。
3. **手术室 03** — 手术照片与规格表；"打开手术灯"会在照片里显出主刀医生的真实侧影。
4. **病例记录** — 三条匿名记录，隐藏文本逐步变成求救。
5. **手术室监控** — 四路画面矛盾：无人值班、恢复室有凹陷、没有排班却有人站定；时间戳会替换成访客本机的真实时间。
6. **手术台终局** — 全屏滚动：真实外科医生照片从黑暗里逼近，中途三帧闪脸，随后"手术结束"假安全画面自行熄灭，最后贴脸收尾。

交互：

- "申请评估"打开虚构术前评估，明确标注不是真实医疗或付费流程。
- 进入后段后，"呼叫主刀医生"接通值班台，回复随阶段变化。
- "打开手术灯"切换手术室照明。
- 右下角值班台可随时打开，`Esc` 关闭并归还焦点。
- 环境音必须手动开启；系统"降低动态效果"时关闭闪脸、贴脸动画与惊吓音效。
- 走廊中停手约 9 秒，医生会继续靠近并出现提示。
- "离开研究所"关闭声音与全部惊吓状态，回到首屏。

## 本地运行

需要 **Node.js 24**，零第三方依赖、无需构建：

```bash
npm start
```

打开 <http://localhost:25798>。

语法检查：

```bash
npm run check
```

## 入口、端口与部署

- 根入口 `index.js`；`npm start` 即 `node index.js`。
- Node `>=24 <25`；监听 `0.0.0.0`。
- 端口优先级：`SERVER_PORT` → `PORT` → `25798`。
- 部署到 Nodaroo：选择 Node 24，`MAIN_FILE=index.js`，把 `index.js`、`package.json`、`public/` 放在同一层上传。
- 从 GitHub 拉取：配置 `GIT_ADDRESS` 与 `BRANCH`；公开仓库无需凭据。令牌只填在面板，不要写进仓库。
- `GET /` 映射 `public/index.html`，静态根只有 `public`；`/health` 返回 JSON；支持 `GET` 与 `HEAD`。
