# MERCY HOUSE / 梅瑟疗养院

以虚构私立疗养院为主题的滚动恐怖网站。页面从一家克制、可信的长期照护机构开始；随着用户向下滚动，住客来信、夜间巡视记录与监控画面逐步暴露出同一件事：这间疗养院没有出院记录，而夜班护士正在走廊里向你的房间走来。

**本项目为原创虚构互动体验，不代表任何真实机构，不提供医疗服务、诊断、建议或预约，也不收集个人、医疗或支付信息。**

## 页面与交互

页面共有六个滚动阶段（`body[data-stage="0"]` 至 `"5"`）：

1. **入院** — 正常的私立疗养院首页：暖白与炭黑、长期照护介绍、房间与护理数据。
2. **照护项目** — 睡眠静养、日常照护、夜间陪护；第三张卡片的文案开始出错。
3. **东翼三号房** — 病房介绍逐步变成“无出口”“永不结束”；走廊灯开关会在房间照片中显出护士。
4. **住客记录** — 好评的另一半被隐藏，显示为没有出院日期的记录。
5. **夜间监控** — 四路监控互相矛盾：空床有两处凹陷、排班为零、护士却仍在门外；时间戳会替换成访客本机的真实时间，第四格标注“你正在被看着”。
6. **夜班走廊** — 全屏滚动场景，恐惧分四拍升级：
   - 护士在走廊深处出现，画面左下角显示“她距离你 N 步”；
   - 滚动到中段时，护士的脸以三帧硬切形式闪满屏幕；
   - 进入尾声先出现“查房结束 / 一切正常”的亮场，约 1.2 秒后灯光自行熄灭并转入黑暗；
   - 最后是贴脸画面与“你已经住下了”。

配合的交互：

- “申请入住”打开虚构的长期照护申请，明确标注不是真实入住或付费流程。
- “了解长期照护方案”在进入后段后会接通夜班值班台，回复内容随阶段变化。
- “打开走廊灯”切换病房照明，并让护士从照片里浮现。
- 右下角夜班值班台可随时打开；`Esc` 关闭并把焦点还给触发按钮。
- 环境音必须由用户主动开启；页面不会自动播放。
- “回到院外”关闭声音、弹窗与终局状态，清空滚动位置和地址锚点，把焦点移回首页标题。
- 系统开启“降低动态效果”时，闪脸、跳吓动画与惊吓音效全部关闭，只保留静态画面。
- 在夜班走廊中停手不动约 6.5 秒，护士会持续靠近，屏幕出现“你没有往下滚”。

## 文件结构

```text
index.js                  # Node HTTP 静态服务入口
package.json              # 启动与检查命令
public/
├── index.html            # 六个章节与所有交互结构
├── styles.css            # 暖白 / 骨色 / 炭黑 / 暗红视觉与响应式
├── app.js                # 滚动阶段、灯光、值班台、声音与终局
├── assets/
│   ├── nurse.svg         # 原创夜班护士全身像
│   ├── nurse-face.svg    # 原创护士贴脸近景
│   ├── ward.svg          # 原创夜班病区长廊
│   └── favicon.svg
└── media/
    ├── suite.jpg         # 病房照片（Unsplash）
    └── ward.jpg          # 病房照片（Unsplash）
```

页面运行时不请求外部图片、字体或脚本。照片来自 [Unsplash](https://unsplash.com/)，护士、病区与图标为项目内原创 SVG。

## 本地运行

需要 **Node.js 24**。项目无第三方依赖、无构建步骤：

```bash
npm start
```

打开 <http://localhost:25798>。

语法检查：

```bash
npm run check
```

该命令检查根入口 `index.js` 与 `public/app.js`，不包含浏览器视觉检查。

## 入口、端口与部署

- 根入口为 `index.js`；`npm start` 即 `node index.js`。
- Node 版本范围：`>=24 <25`；服务器监听 `0.0.0.0`。
- 端口优先级：`SERVER_PORT` → `PORT` → `25798`。
- 部署到 Nodaroo 时，选择 Node 24，`MAIN_FILE` 设为 `index.js`，把 `index.js`、`package.json`、`public/` 放在同一层上传；无需上传 `node_modules` 或 `.git`。
- 从 GitHub 拉取时配置 `GIT_ADDRESS` 与 `BRANCH`；公开仓库不需要凭据。私有仓库的令牌只填在面板里，不要写入仓库或发给他人。
- `GET /` 对应 `public/index.html`，静态根目录只有 `public`；`GET /health` 返回 JSON 状态；静态资源支持 `GET` 与 `HEAD`。
- 面板服务器的公网地址与端口以控制台实际显示为准。
